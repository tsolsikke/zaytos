# 0042. ファイルの置き場所の規約——FHSに従い、従わない場所は名前で断る

## Status

Accepted

## Date

2026-08-22

## Context

**`mkdir`が無いので、ディレクトリは像を建てるときにしか作れない。** いま在るのは4つだけである（実測。`debugfs`で読んだ）。

| 名前 | 中身 |
|---|---|
| `/bin` | 実行ファイル8本（`bss-test` `cat` `hello` `ls` `spawn-test` `spin` `zash` `zi`） |
| `/data` | 検査の種5つ（`lines` `writable` `direct-max` `indirect-first` `sparse-hole`） |
| `/etc` | `motd` 1つ |
| `/lost+found` | `mke2fs`が作る |

**`mkdir` / `rmdir` / `rm` / `touch`を作る段（DIR(1)）で、置き場所の規約を決める必要が出た。**

**規約を決めるのは早いほどよい。** **パスは写しが散る**——**いま`/data`を指している箇所は、コードで75、文書で31、合わせて106である**（実測）。**この数は段を重ねるたびに増える。**

### 決めることと、作ることは別である

**「使う者がいない機構は検算が置けない」**（`docs/verification-coverage.md`）。**空のディレクトリを先回りで作ると、その規律に反する。**

**しかし規約は、作らなくても決められる。** **決めるのは無料で、作るのは費用がある。** **この ADR は規約を決め、作るのは利用者が来たものだけにする。**

## Decision

### 1. FHSに従う。**従う範囲を名前で挙げる**

| 場所 | 何を置くか | いま作るか |
|---|---|---|
| `/bin` | **すべてのコマンド。** `/sbin`と分けない | 在る |
| `/etc` | 設定。いまは`motd`。**環境の源を置くならここである**（ADR-0041の却下案(b)） | 在る |
| `/tmp` | 一時ファイル。**誰が消すかは決めていない**——**当時は「書き込みが再起動で消える」ことが答えだった**（ADR-0037）。**その前提はP-dで消えた**（`ADR-0051`）。**`/tmp`は起動をまたいで残る。** **誰が消すかは開いた問いである**（`docs/deferred-decisions.md`に行が在る） | 在る |
| `/home` | 利用者のファイル | **作らない**（利用者の概念が無い） |
| `/var` | 変化する状態（記録・待ち行列） | **作らない**（置くものが無い） |
| `/usr` | —— | **作らない。使わない**（下記） |
| `/sbin` | —— | **作らない。使わない**（下記） |
| `/lib` | 複数のプログラムが共有するデータ（フォント・`terminfo`・ロケール）と、来るなら共有ライブラリ | **作らない。保留**（下記） |
| `/dev` | 特殊ファイル | **作らない**（DIR(2)の判断） |
| `/proc` | 仮想ファイルシステム | **作らない**（DIR(3)の判断。ADR級） |

### 2. 使わないと決めた2つ

- **`/sbin`を作らない。** **管理者と利用者の区別が無い**（権限の概念が無い）。**分ける基準が無いものを分けない。**
- **`/usr`を作らない。** **FHSの`/usr`は「二次階層」で、`/bin`との分割は歴史的な事情（起動に要るものと要らないもの）である。** **ZaytOSは像を丸ごとRAMへ読む**（ADR-0034）ので、**分割の理由が存在しない。**

**2つとも「まだ作らない」ではなく「使わないと決めた」である。** **後で必要が出たらこの ADR を更新する**——**空のまま置いて、誰かが何かを入れるのを待つ形にしない。**

### 2-2. `/lib`は保留にする。**使わないと決めない**

**`/lib`の用途は動的リンクだけではない。** **複数のプログラムが共有するデータの置き場でもある**——フォント・`terminfo`・ロケールがそれである。

**ZaytOSには既に共有されるデータが1つある**——**フォント（GNU Unifont）である。** **いまはカーネルに焼き込んでいる**（`kernel/src/graphics/font/`）ので`/lib`は要らないが、**GUIの段でプログラム側がフォントを読む形になれば、置き場が要る。**

**`terminfo`はC移植で来る見込みである**（`ncurses`相当が端末の能力を引くとき）。

**したがって「使わないと決めた」側に入れない。保留である。**

**解禁の契機は2つで、どちらか早いほうである。**

1. **動的リンクを扱うとき**
2. **複数のプログラムが共有する何かを、像の中に置く必要が出たとき**（フォント・`terminfo`・ロケール）

**契機が来たらこの ADR を更新して、`/lib`の行を「作る」へ動かすこと。**

### 3. `/data`は残す。**FHSに無い名前であることを明記する**

**`/data`の中身は検査の種である**——`lines`（`zi`が編集する4行）、`writable`（書き込みの的）、`direct-max` / `indirect-first`（単一間接の刻み）、`sparse-hole`（穴あき）。**利用者に見せるためのものではない。**

**移さない理由は2つある。**

1. **移してもFHSに近づかない。** **FHSに「検査の種」の置き場は無い。** `/usr/share`（静的な共有データ）が近いが、**`/usr`を使わないと決めた**（決定2）。`/var/lib`も候補だが、**あれは「プログラムが書き換える状態」で、こちらは像に焼いた定数である。**
2. **費用が106箇所で、得るものが名前だけである**（実測）。**書き換えは機械的だが、判定の期待値と`build.rs`の staging が全部動く。**

**そのかわり規約を書く。** **利用者のファイルは`/home`へ、検査の種は`/data`へ。** **`/data`はFHSに無い名前であり、意図してそうしている。**

### 4. 新しい場所を足すときの規則

**この表に無い場所を作るときは、この ADR を更新すること。** **像を建てる`kernel/build.rs`と、この表が食い違ったら、表のほうが古い。**

## Alternatives Considered

### (a) 6つ全部（`/home` `/tmp` `/usr` `/var` `/sbin` `/lib`）を作る

**却下する。** **5つは置くものが無い。** **空のディレクトリは、`ls`に出るだけで何も主張しない**——**「使う者がいない機構は検算が置けない」の、いちばん分かりやすい形である。**

**費用も0ではない**——**1つにつきinodeが1つとブロックが1つ**（実測で像は512ブロック中418が空きなので余裕はあるが、**余裕があることは作る理由にならない**）。

### (b) `/data`を`/usr/share/zaytos`か`/var/lib/zaytos`へ移す

**却下する。** 理由は決定3にある。**費用106箇所に対して、得るものが名前だけである。**

**この却下は、費用が測れているから言える。** **測らずに「散る前に動かす」と決めると、動かした先がFHS的に正しいかを問わないまま費用だけ払うことになる。**

### (c) 規約を決めず、DIR(1)では`mkdir`だけ作る

**却下する。** **`mkdir`が入った瞬間から、置き場所は増える。** **増えてから決めると、決めた規約に既存が従っていない状態から始まる。**

## Consequences

**得るもの。**

- **置き場所を問われたときに、答えが1箇所にある。**
- **作るものが少ない**——`/tmp`1つだけである。
- **`/data`の異物感が、記録された判断になる**（**次に読む者が「直し忘れ」と誤解しない**）。

**失うもの・引き受ける制約。**

- **`/home`が無いので、利用者のファイルの置き場が実在しない。** **`zi`で作るファイルは`/data`か`/tmp`へ置くことになる**——**規約としては`/tmp`である。**
- **`/usr`を使わないと決めたので、Cの移植で`/usr/include`相当を期待する道具が来たら、この ADR を更新することになる。**
- **`/lib`を保留にしたので、置き場所が要るまで決まらない。** **決まっていないことが分かる形で残してある**——**「使わない」と読まれると、フォントや`terminfo`の置き場を探す者が候補から外してしまう。**

**将来のトレードオフ。**

- **`/dev`（DIR(2)）と`/proc`（DIR(3)）は、この表に場所だけ空けてある。** **中身の判断は別の ADR である。**
