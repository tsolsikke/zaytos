# 0043. コマンドは外部に置き、`PATH`で探す——組み込みはシェル自身の状態を変えるものだけ

## Status

Accepted

## Date

2026-08-23

## Context

**DIR(1)で`rm` / `mkdir` / `touch` / `rmdir`（と`tail`）を作る。** **組み込みにするか、`/bin`の実行ファイルにするかを先に決める。**

### 実測——基準は既に在り、記録先も判断済みである

**`kernel/userland/zash.rs`の`run_line`の doc に、基準が書いてある。** **Linuxで組み込みになる理由は3種類あり、そのうち1つだけがZaytOSで成り立つ、という形である。**

| Linuxの理由 | 例 | ZaytOSで成り立つか |
|---|---|---|
| (1) シェル自身の状態を変えるので、外部では実装できない | `cd` `exit` `export` `umask` | **成り立つ。`exit`がこれである** |
| (2) 速さのため | `echo` `test` `pwd` | **成り立たない。** `spawn`は同期で1本ずつなので、比べる相手がいない |
| (3) 文法の一部 | `if` `while` `for` | **まだ来ていない。** 制御構造が無い |

**あの doc は「ADRは起こさない」と判断している**（`docs/coding-standards.md`の条件3つに当て、当たらなかった理由まで書いてある）。**その判断は基準についてのもので、いまも有効である。** **この ADR が記録するのは別の2つ**——**一覧（どのコマンドがどちら側か）**と、**`PATH`を採る判断**である。

### 実測——いまの姿

- **組み込みは`exit`だけである**（`BUILTIN_EXIT`。分岐は`run_line`に1つ）
- **`/bin`に同じ名前の実体は無い**（`bss-test` `cat` `hello` `ls` `spawn-test` `spin` `zash` `zi`の8本。`exit`は無い）。**二重は1つも無い**
- **`/`を含まない語は`/bin/`の下で探す**（`DEFAULT_DIR`。**`PATH`ではない。固定の既定で、探索の順序も無い**）
- **`zash`は16992バイト、外部のコマンドは1本あたり約12KiBで3ブロック**（実測。像は512ブロック中418が空き）
- 台本は両方の形を通している——**`/bin/ls`のようにパスを直に打つ形が7箇所**（`kernel/src/input.rs`）と、**`ls`のように名前だけで打つ形**（`xtask`の`SHELL_TEST_LINES`）

### 実測——置き換えの条件が発火した

**`DEFAULT_DIR`の doc は、置き換えの条件を「`envp`を開けたとき」と書いている。** **EV（ADR-0041）で開いた。**

**書いただけの条件は発火しない**——この体制が何度も踏んできた形である（`docs/deferred-decisions.md`の遠征スタックの行、`install_kernel_stack_guard_page`）。**発火したのだから、ここで決める。**

## Decision

### 1. 組み込みは「シェル自身の状態を変えるもの」だけにする

**基準は`zash.rs`の doc のとおりで、変えない。** **理由(2)（速さ）と(3)（文法）は採らない。**

### 2. **いまの該当は`exit`だけである。DIR(1)のコマンドは全部外部にする**

`rm` `mkdir` `touch` `rmdir` `tail` `ls` `cat`——**すべて`/bin`の実行ファイルにする。** **どれもシェル自身の状態を変えない。**

**`cd`と`export`が来たら組み込みになる。** **ただし、いまは該当が無い。**

- **`cd`——カレントディレクトリが無い。** カーネルの`lookup`は常にルートから辿る（`common::ext2`）
- **`export`——環境はカーネルが1つ持ち、プロセスごとに変えられない**（ADR-0041のDecision 2）

**この2つは「まだ作っていない」のではなく、「変える対象が存在しない」のである。** **対象ができた段で、この決定に従って組み込みになる。**

### 3. **`PATH`を採る。`zash`は`PATH`で探す**

**環境に`PATH=/bin`を足し、`DEFAULT_DIR`の固定の既定を置き換える。**

**探索は左から順、区切りは`:`。** **最初に開けたものを起こす。**

### 4. **`PATH`はいま固定の既定と同じくらい固定である。承知のうえで採る**

**環境はカーネルの定数である**（ADR-0041）。**したがって`PATH`を足しても、運用者が起動ごとに変えられるようにはならない。** **変えられるようになるのは、環境の源を設定できるようになったとき**（ADR-0041の却下案(b)。**永続化の後**）。

**それでも採る理由は3つある。**

1. **置き換えの条件が発火した。** **書いただけの条件を残さない**
2. **形が標準になる。** **外から来るCのプログラムは`PATH`を前提にする**——`execvp`も`system`も`PATH`を引く。**固定の既定は、その時に必ず作り直しになる**
3. **判定が置ける。** **`PATH`が届かなければ、名前だけで打った語が起こせなくなる**——**`--shell-test`の「bare names resolved under /bin」がそのまま受け止める**（既に在る判定である）。**破壊`env-drop-path`が、その形でしか落ちない判定を持つ**

## Alternatives Considered

### (a) `PATH`を作らず、`/bin/ls`のようにパスを直に打つ形だけにする

**却下する。** **打ちやすさを失う**——運用者は`ls`と打ちたい。**そして台本の片方（名前だけで打つ形）が消えるので、判定が1本減る。**

### (b) `PATH`を作らず、`zash`が`/bin`だけを固定で探す（いまの形のまま）

**却下する。** **動くのは事実である**——**費用0で、いまと同じ振る舞いになる。**

**却下の理由は、条件が発火したことである。** **`DEFAULT_DIR`の doc が「`envp`を開けたら置き換える」と書いており、開いた。** **ここで採らないなら、あの条件を書き直す必要がある**——**「開けたとき」ではない別の条件へ。** **書き直せる条件が思いつかない**（`PATH`が要るのはCの移植だが、**それは段の名前であって発火の契機ではない**）。

### (c) `ls`と`cat`を組み込みにして、`/bin`から外す

**却下する。** **基準の(2)（速さ）に当たるが、その理由をZaytOSでは採らないと決めている。** **そして`bash`も外部の`/bin/echo`を持っている**——**組み込みは「外部が無くてよい」という意味ではない。**

**移行の費用も測った。** **`ls`を組み込みへ寄せると、台本の`/bin/ls`（7箇所）が「外部が無い」形になる。** **外部を残せば二重になり、どちらが動いているかを判定が言えなくなる**——**いま二重は1つも無い**（実測）。**その性質を捨てる理由が無い。**

### (d) `PATH`を空にできる形（POSIXの「空要素はカレントディレクトリ」）を入れる

**却下する。** **カレントディレクトリが無い。** **空要素に意味を与えられない。**

## Consequences

**得るもの。**

- **どちらに置くかを、名前ごとに議論しなくてよい**（基準と一覧がある）
- **`PATH`が標準の名前で在るので、Cの移植で作り直しにならない**
- **環境が「読まれている」ことの判定が、`TERM`に続いて2本になる**

**失うもの・引き受ける制約。**

- **`PATH`はいま変えられない。** 固定の既定と実質同じである（決定4）
- **`zash`が少し大きくなる**（`:`で割って順に試す処理。見積もりで数十行）
- **探索の順序が意味を持つようになる。** **要素が1つのうちは差が出ないが、2つ目が来たときに「最初に開けたもの」の規則が効く**

**将来のトレードオフ。**

- **`cd`が来たら、作業ディレクトリを誰が持つかの判断が要る**（`zash.rs`の doc が3点を挙げている。`openat`を置かなかった前提もそこで消える）
- **環境が設定できるようになったら、`PATH`が最初の利用者になる**

## 決めないこと

- **探索順の細かい規則**（左から、最初に開けたもの、以上）
- **エイリアス**
- **組み込みが外部を上書きする規則**（いま二重が無いので、規則を作る対象が無い）
- **`type`相当**（何がどちらで動くかを問うコマンド）
- **`PATH`が空、または要素が無いときの振る舞い**（**いまは起こせないだけである**）
