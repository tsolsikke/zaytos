# 0057. Cのプログラムは自前のlibcで、SSEを使わずに建てる

## Status

Proposed

## Date

2026-09-06

## Context

GUIの段でotf/ttfを載せるには`stb_truetype`相当が要り、自作するとラスタライザが数千行になる
（`docs/roadmap.md`の「otf/ttfは順序で費用が10倍変わる」）。**そのためCのプログラムを走らせる道が要る。**

**現在地は実測である**（2026-09-06）。

- **`gcc` 13.3.0が手元に在る**（`clang`は無い）。
- **ELFローダは静的リンク専用である**（`common/src/elf.rs`。`ET_EXEC` / `EM_X86_64` / `PT_LOAD`のみを
  写像し、`PT_INTERP`も`PT_DYNAMIC`も扱わない）。
- **既存の`kernel/userland/user.ld`がそのまま使える。** freestandingの`hello`を建てたところ、
  **エントリ`0x400000` / `PT_LOAD`2つ / 8,808バイト**になり、受け入れ条件をそのまま満たした。
- **カーネルはSSEを有効にしていない**（`CR4.OSFXSR` / `OSXMMEXCPT`、`CR0.MP` / `EM`を書く箇所が0）。
  **文脈切り替えでFPの状態も保存していない**（`fxsave` / `xsave`が0箇所）。**プリエンプションは在る。**

## Decision

**5つ決める。**

1. **自前のlibcを書く。** 外のlibc（`newlib`等）は持ってこない。**面は7つに絞る**——
   起動と終了／`int 0x80`の呼び出し規約／標準入出力／`brk`の上の`malloc`／`str*`と`mem*`／
   終了状態／**`errno`は素のグローバルにする**（単一スレッドなのでTLSを使わない）。
2. **静的・非PIEで建て、既存の`user.ld`を使う**
   （`gcc -ffreestanding -nostdlib -no-pie -static -T kernel/userland/user.ld`）。
3. **SSEを使わずに建てる**（`-mno-sse -mno-mmx -mno-80387`）。
   **ABIの選択なので、libcも利用側も同じフラグで建てる。**
4. **建てる場所は`kernel/build.rs`の1箇所に保つ。**
   **いま`rustc`を呼ぶ箇所はリポジトリ全体で1つで、Cも同じ場所へ足す。**
5. **純粋ロジックは`common`へ置き、ホストで固定する**（`ADR-0045`と同じ形）。

## Alternatives Considered

### (a) SSEを有効にする

**採らない。** **この段では要らないことを測った**（2026-09-06。`gcc` 13.3.0、`-O2`）——
**手で書いた最小のlibc（`memcpy` / `memset` / `strlen` / `strcmp` / `strcpy`）はSSE命令を0個しか
出さず、利用側で出た8個も64バイトの構造体の代入1つからで、`-mno-sse -mno-mmx -mno-80387`を
付けると0個になった。**

**費用は「2ビットを立てる」では済まない。** **文脈切り替えでFPを保存していないのに
プリエンプションが在るので、有効にするだけでは状態が壊れる**——**保存・復元をスケジューラと
遠征の経路へ入れることになり、レビュー必須の面が2つ増える。**

**利用者が無いいま入れるのは先回りである**（`CLAUDE.md`の「先回りの抽象化・作り込みをしない」）。
**外のCを持ってくるときに、そのときADRを書く**（持ち越しの「FPU / SSEの状態保存」の行）。

### (b) `newlib`等を持ってくる

**採らない。** **面が要るぶんだけ広がるのではなく、道具が要求する面が全部ついてくる。**
**いま要るのは7つで、持ってくると`fork`・時刻・localeまで抱える。**
**外の道具を実際に移す段で、そのとき測って決める。**

### (c) `-Ttext=0x400000`だけで建てる

**採らない。** **実測で`PT_LOAD`が3つになり、1つが`0x3ff000`（像より下）へ出た。**
**`user.ld`を通せば2つに収まる。**

### (d) `clang`を使う

**採らない。** **手元に無い**（`gcc` 13.3.0のみ）。**入れる理由が無い。**

## 決めないこと

**外のCの道具をどれ持ってくるか。** **浮動小数点を使うプログラム。**
**`syscall` / `sysret`への差し替え**（自前のlibcが`int 0x80`を出すので要らない。TLSも要らない）。
**`ioctl`の入口**（`termios`は対話する道具を移す段である）。**時刻の欄。**

**libcの面のうち作らなかったもの**——**穴を管理する`malloc`、`printf`、`stdio`の緩衝。**
**ここは決定の範囲を書く場所なので、いつ要るかは`docs/deferred-decisions.md`の行に在る**
（3本立てた。2026-09-06）。

## Consequences

- **Cのプログラムが`/bin`に置けるようになる。**
- **像の上限（32KiB）に当たる見込みが上がる**——**いま`zash`が29,248バイトで、余裕は3,520バイトである。**
  **測ってから上げる**（段のd）。**→ 測って、上げないと決めた**（2026-09-06。
  **`chello`はlibcを積んで9,712バイトで、上限の30%である**——**当たりそうなのは
  Rustの`zash`のほうで、Cの側ではない。** 持ち越しの行に契機を書いた）。
- **浮動小数点を使うCは、この段では建たない。** **外のCを持ってくるときにSSEの段が要る**
  （**外すときに要ることは持ち越しの行に書いてある**——**フラグを外すだけでは済まない**）。
- **libcの面が7つで止まるので、移せるCの道具は限られる。** **どれを移すかは、移すときに決める。**

## Addendum（2026-09-09。Bの段で2つ変わった）

**丸ごとSupersededにはしない。** **変わったのは2つで、残りはそのまま生きている。**

**(1) Decision 3（SSEを使わずに建てる）は役目を終えた。** **`ADR-0058`がSSEを有効にし、
切り替えと遠征でFPの状態を退避するようにしたので、B-aで`-mno-sse -mno-mmx -mno-80387`を
外した。** **理由は`stb_truetype`が`-mno-sse`では建たないことである**
（実測。`SSE register return with SSE disabled`でコンパイルが止まる）。
**Decision 3の後半——「ABIの選択なので、libcも利用側も同じフラグで建てる」——は
そのまま生きている。**

**(2) libcの面が7つから8つになった。** **8つ目は数学の最小面で、4つある**
——`fabs` / `floor` / `ceil` / `sqrt`（`kernel/userland/libc_math.c`）。
**`stb_truetype`がビットマップの経路で呼ぶのがこれだけだからである**
（実測。2026-09-09。**呼び出し箇所を呼び出し元の関数ごとに分類した**——
`fmod`と`pow`と`cos`と`acos`はSDFの経路にしか出ない）。

**面を広げるときの規律は変えていない。** **「決めないこと」に挙げたものは、
挙げたまま残っている**——**穴を管理する`malloc`・`printf`・`stdio`の緩衝は、
まだ作っていない。**

**数学の面の契約**——**`errno`を据えない**（Cの標準が実装依存としており、
`stb_truetype`は戻り値しか見ない。実測）。**丸めはIEEE 754に従う**
（`sqrt`は`sqrtsd` 1命令で、MXCSRのRCに従う。既定は最近接偶数）。
**負の入力には、命令が定める値をそのまま返す**（`sqrt(-1)`はQNaN。
**ビットマップの経路で渡るのはいつも2乗の和なので、負は来ない**——実測）。
